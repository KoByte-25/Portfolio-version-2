Project Description

"ByteLoc" Andriod GPS Tracker is a simple Android GPS tracker app built with Flutter, designed for demos, testing, and learning rather than production use. It continuously reads the device's location and sends JSON payloads every 1 second via HTTP POST to a configurable endpoint user define.

Key features:
- Continuous GPS tracking while the app is open
- Real internet connectivity detection (Wi‑Fi or mobile data) with a clear green/red "Online / Waiting for network…" status banner
- Editable tid (Tracker ID) and deviceId identifiers saved on the device
- Sending automatically pauses while editing URL/TID/Device ID and resumes after saving
- Quit confirmation dialog when using the back button
- Help screen explaining usage, requirements, and battery/privacy notes


How to use:
1. Install on an Android device with Location enabled and internet access
2. Grant Location permission when prompted
3. Set your HTTP endpoint URL, TID, and Device ID by tapping the respective lines
4. The app sends JSON once per second only when internet is available, GPS has a valid position, URL is non-empty, and you're not editing settings
5. Pressing back shows a confirmation to stop sending and quit
